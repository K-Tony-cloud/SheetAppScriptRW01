แบบฟอร์มลงข้อมูลใหม่

1. วัน / เดือน / ปี / มีหมายเสด็จหรือไม่
2. ข้อมูลการตรวจพบและการนำส่ง
ถ่ายภาพบุคคลตรวจพบ → บันทึกในหมวด "officer_found" หลังบันทึกข้อมูลแล้ว
3. จุดที่อยู่สิ่งของและสิ่งของที่นำมายื่นฯ
ถ่ายภาพสิ่งของ/หลักฐาน → บันทึกในหมวด "items_evidence" หลังบันทึกข้อมูลแล้ว
4. ข้อมูลส่วนตัวของผู้ถวายฎีกา
ถ่ายภาพผู้ยื่นถวายฎีกา → บันทึกในหมวด "person_portrait" หลังบันทึกข้อมูลแล้ว
